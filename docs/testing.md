前端 `npm test`（`node --test`）除纯函数单测外，还有 `src/appContract.test.js` 校验 `createApp()` 组装出的 ctx 覆盖页面组件 `inject('app')` 依赖的全部键，并用 fetch stub 跑通「登录 → 拉列表」链路。

HTTP 链路测试位于 `internal/router`（装配后打真实请求，同时校验新路由结构与旧路由已下线；按领域拆为 `source_test.go` / `video_test.go` / `category_test.go` / `task_test.go`，共用 helper 在 `helpers_test.go`），采集编排测试位于 `internal/service`，协议解析测试位于 `internal/service/collector`，纯工具测试位于 `internal/utils`；`internal/repository` 下按实体拆为 `asset_test.go` / `source_test.go` / `video_test.go` / `job_test.go` / `user_test.go`，另有 `store_test.go` 校验连接与各对象装配、`crawl_cache_test.go` 校验采集会话类目缓存、`mysql_search_test.go` 校验 MySQL 后端的关键词检索 SQL 形态（ngram FULLTEXT 短语表达式、1 字与含通配符降级 LIKE、DSN 参数规范化、方言识别、GORM 自动生成 ON DUPLICATE KEY UPDATE，全部用 GORM `ToSQL` 在 DryRun 下生成、无需真实 MySQL 实例）。HTTP 链路测试会自动注册首个管理员并让所有请求携带令牌，真实模拟登录后访问。SQLite 使用纯 Go 的 modernc.org/sqlite 驱动（经 github.com/glebarez/sqlite 接入 GORM），无需本机 gcc，测试直接运行即可（`CGO_ENABLED=0`）。

端到端可用模拟站点验证：68 个标准字段全部落库、`extra` 保留自定义字段与嵌套对象及被裁剪字段（不再存整条 `raw`）、只改一个冷门字段也能触发更新、全量/增量/去重/幂等/批量采集、按站点自动分类归档与 Vue 页面托管均正常。
